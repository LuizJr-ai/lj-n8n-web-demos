# ADR — Architecture Decision Records

Purpose: índice e convenção dos registros de decisão deste projeto. Um ADR só nasce quando a
decisão está **tomada** (não "a decidir").

## Convenção
- Nome: `NNNN-titulo-curto.md` (numeração sequencial, imutável).
- Headings obrigatórios: `## Status`, `## Contexto`, `## Decisão`, `## Consequências`.
